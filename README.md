# Klinkari Tarot

A quiet, single-card reflection experience featuring the ten original Klinkari cards. The KLINKARI card and artwork from the supplied archive are included in the deck.

## Open

Open `index.html` in a browser. The site is static and needs no build step or account. Use **Draw a card** to reveal a card; the deck cycles through each card before reshuffling and avoids repeating the last card immediately.

## Customize

Edit the card names and image paths in `app.js`. Artwork lives in `cards/`; update the matching image path when replacing a card. Page copy and styling are in `index.html` and `style.css`.
